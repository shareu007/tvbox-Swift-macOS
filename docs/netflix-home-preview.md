# 首页影院布局预览

## 状态

- 分支：`feat/netflix-home-preview`
- 基线：`3fa9390`
- 仅在独立 worktree 开发。等待用户审阅后再合并；不推送、不发布、不替换本机安装版。

## 改动

- 大封面展示当前来源的前五部推荐，可用指示条或左右按钮切换。
- 影片名称、已有年份/地区/类型、简介和「查看影片」入口集中在封面上。
- 分类改成简洁文字导航，选中项用橙色下划线标识。
- 推荐片单采用横向海报架；封面缺失时保留占位和可点击标题。
- 普通分类网格、来源菜单、年份/地区/类型筛选、分页、刷新与错误重试继续沿用。
- 首页随现有浅色/深色主题切换；封面自身使用深色遮罩保证文字可读。
- 首页视觉组件独立放在 `HomeCinemaView.swift`，没有修改播放器或接口适配逻辑。

## 验证

- macOS arm64 Release 构建。
- `HomeCategoryGroupTests`、`HomeBrowseFilterTests`：31 项分类、筛选、分页回归。
- `HomeCinemaLayoutTests`：宽屏浅色、宽屏深色、窄屏长标题/无封面三组截图。
- 测试海报在内存中绘制，不使用用户接口、Cookie 或真实影片截图作为仓库素材。
- 编译和截图继续复用主工作目录唯一的 `build/DerivedData`，不在 worktree 创建第二套编译目录。
- 最终 34 项检查通过；Release 签名校验、安装包内容隐私扫描通过。
- 实际应用窗口连接连续返回 `cgWindowNotFound`，真实接口下的鼠标点击尚未完成验证。截图由挂载在 macOS 窗口中的真实 SwiftUI 组件生成。

## 预览范围

- 首页封面来自接口现有海报。接口没有横版背景图时，使用海报裁切、模糊延展与渐变衔接；没有新增图片服务或后台请求。
- iOS 使用相同组件并保留底部导航；此次编译和布局截图在 macOS 完成，iOS 未做设备运行验证。
