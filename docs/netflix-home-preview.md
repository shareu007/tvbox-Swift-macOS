# 首页与剧集详情布局预览

## 状态

- 分支：`feat/netflix-home-preview`
- 基线：`3fa9390`
- 仅在独立 worktree 开发。等待用户审阅后再合并；不推送、不发布、不替换本机安装版。

## 当前布局

- 首页不展示大海报，保留简洁分类、筛选和横向海报片单。
- 点击资源后的详情页使用电影式封面、片名、已有元数据、简短介绍，以及播放/收藏/下载按钮。
- 播放开始后，大封面收为紧凑的信息区；播放器保持在顶部，解析出播放地址时自动滚回顶部。
- 线路选择放在选集标题旁，清晰度使用菜单，减少原来的多层卡片和重复标题。
- 选集使用编号列表，当前集突出显示；每 50 集分组，恢复播放时定位到当前集所在分组。
- 完整介绍、导演与演员放入可展开的「关于本片」。
- 页面跟随现有浅色/深色主题。封面使用深色遮罩，保证文字与操作按钮可读。
- 接口只有影片海报时复用现有海报裁切与模糊延展，不请求新增图片服务，不虚构单集缩略图、评分或时长。
- 播放引擎、全屏切换与播放器控件沿用现有实现。
