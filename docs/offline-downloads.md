# 离线下载

## 使用方式

1. 打开影片详情，先选择播放线路，再点击“下载”。
2. 选择一集或多集，加入下载队列；同一接口、影片、线路和剧集不会重复添加。
3. macOS 侧边栏打开“下载”；iOS 在个人中心打开“离线下载”。可查看进度、速度、错误原因，暂停、继续、重试或删除任务。
4. 完成后点击“播放”，直接读取本地文件，不依赖当前接口加载成功。重启应用后未完成的任务保持暂停，点击继续才恢复网络请求。

本轮源码构建号为 macOS 24，未安装到本机，也未发布 DMG。

## 支持范围

- 支持可直接读取的 HTTP(S) MP4、Matroska/WebM、FLV、TS 文件。保持原始媒体字节，内嵌字幕随文件保留。
- 支持有限长度点播 HLS，主清单选择较高带宽的变体；下载分片、AES-128 密钥及 `EXT-X-MAP` 初始化片段。生成的本地清单只引用本目录中的文件。
- 解析沿用当前来源及账号状态，包括 CatVod、网盘解析结果；不额外保存 Cookie 或重新登录。来源必须实际返回可下载的媒体地址。
- 单纯保存的本地 M3U8 不能由系统播放器直接播放。选择系统播放器时，本地 HLS、MKV/WebM、FLV、TS 在 macOS 使用内置 mpv，在没有 mpv 的平台使用 VLC；显式选择 mpv/VLC 的偏好保留，在线播放和原生 MP4 播放行为不变。
- 直播、DRM / SAMPLE-AES、独立音视频轨、字节范围 HLS 和部分扩展暂不支持，会显示原因。来源外挂字幕、本地导出和退出应用后继续后台下载尚未包含。

## 续传和速度

- 同时最多 2 个任务，每个 HLS 最多并发 4 个片段，没有人工限速。网络数据块直接写盘，不逐字节处理或将整部影片读入内存。
- 直链使用 `Range` / `If-Range`；要求来源提供强 ETag 或 Last-Modified。服务器忽略 Range 时清空旧部分文件后重新下载；范围异常或 HTTP 416 只尝试一次完整请求。
- URL 或请求凭据变化时不复用旧直链部分文件。HLS 只复用清单、资源地址和请求身份完全相同的完整片段；变化时重新下载，避免混合内容。
- 最多保存 500 个任务；每个直链 / HLS 任务限制约 100 GiB，单个 HLS 片段限制 512 MiB，清单限制 2 MiB / 20000 项。超过上限明确失败，不显示为下载完成。
- 真实速度仍受来源服务、网盘账号、网络和所选码率影响。测试中的并发数验证不代表外部来源的带宽保证。

## 存储与隐私

- 文件位于应用私有的 `Application Support/TVBox/OfflineDownloads`，使用 UUID 目录名，排除系统备份。目录权限 0700、索引和下载文件权限 0600。
- 索引保存用户选择的来源 / 剧集身份和进度，不保存播放解析返回的 HTTP 请求头及临时签名地址。直链剧集本身的地址仍属于私有任务记录。
- 恢复下载时重新解析，使用当前账号凭据。续传元数据与 HLS 缓存身份对媒体地址及来源鉴权请求头只保存哈希；另保存服务器 ETag / Last-Modified 用于续传。
- 下载会话禁用共享 Cookie、凭据存储和 URL 缓存。跨域重定向清除来源请求头，阻断 HTTPS 降级和非 HTTP(S) 地址；HLS 子资源只在同源继承请求头。
- 暂停 / 删除会取消传输；删除等待最后一次写入结束。过期进度回调通过任务代次和状态校验，不会复活删除的任务。损坏的索引保留原文件，不静默覆盖。
- 播放器保持原有协议限制。为兼容 FFmpeg 对本地密钥路径的扩展名检查，自动生成的 16 字节密钥使用 `.key.ts` 文件名，没有扩大可访问的协议或路径。

## 验证

- 28 项离线下载测试通过；另外 39 项播放器、字幕、来源验证和启动回归通过。
- 离线下载测试覆盖字节完整性、暂停续传、忽略 / 拒绝 Range、身份变化、HTTP 错误、截断、大小上限、任务去重、并发限制、删除与迟到回调、重启、损坏索引、批量添加及隐私边界。
- 使用仓库自带的合成 MP4：下载后可由 AVFoundation 读取时长及两份内嵌字幕。
- 使用 ffmpeg 从合成媒体生成普通与 AES-128 HLS，完成下载后删除模拟来源文件，验证本地 mpv 播放进度、时长和 VideoToolbox 硬解。
- 渲染并检查 440 / 1000 点宽度的下载管理截图，附件保存在 XCTest 结果中。没有完成真实第三方账号的下载或人工端到端点击验收。
- iOS 构建尝试被本机缺少 iOS 26.5 平台阻断，未安装开发平台，不能声称 iOS 运行验证通过。

下载委托依据 Apple [URLSessionDataDelegate](https://developer.apple.com/documentation/foundation/urlsessiondatadelegate)；系统 HLS 离线资产格式参考 Apple [Using AVFoundation to play and persist HTTP live streams](https://developer.apple.com/documentation/avfoundation/using-avfoundation-to-play-and-persist-http-live-streams)。
