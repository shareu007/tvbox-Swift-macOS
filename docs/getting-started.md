# 使用指南

[返回首页](../README.md) · [下载与版本说明](https://github.com/shareu007/tvbox-Swift-macOS/releases)

## 安装

### Mac

1. 下载稳定版中的 `TVBox-macOS.dmg`。
2. 打开 DMG，将 TVBox 拖入“应用程序”；更新时先退出应用，再替换旧版。
3. 从“应用程序”打开 TVBox，首次使用时添加自己的接口。

当前 Mac 安装包支持 macOS 14 及以上，兼容 Apple Silicon 与 Intel，采用 ad-hoc 签名，尚未经过 Apple 公证。

### iPhone / iPad

下载移动端预览版中的 `.ipa` 文件。当前提供的是未签名通用设备包，要求 iOS / iPadOS 17 及以上，需要自行签名后侧载，不能直接点击文件安装。

预览版的版本号、构建号和已知限制，以对应 Release 为准。GitHub 的 `Source code` 压缩包是源码，不是应用安装包。

## 添加与切换接口

在“设置 → 添加点播接口”中输入地址并加载。成功添加的接口保存在“我的点播配置”，之后可切换或移除。

同一个接口可能包含多个来源。首页右上角切换的是当前配置中的首页来源；更换整个接口请到“我的点播配置”。影视内容、分类、海报与播放线路均由来源提供。

## 播放与字幕

进入影片详情后选择线路和剧集。播放器中的字幕菜单会列出能够识别的内封字幕，以及接口实际返回的外挂字幕；可选择其中一份或关闭字幕。

- 没有可选字幕时，先确认视频或来源是否提供字幕轨、字幕地址。
- 已经压制在画面上的字幕不能拆分、切换或关闭。
- Mac 的 mpv 支持字幕时间偏移，适合调整可选字幕与画面的同步；不同版本片源的时间轴差异也会造成字幕不同步。

## 离线下载

1. 在影片详情选择线路，点击“下载”，选择一集或多集加入队列。
2. 在下载管理中查看进度、速度与失败原因，或暂停、继续、重试任务。
3. 下载完成后点击播放，应用读取本地文件。

支持可直接读取的视频文件和普通点播 HLS。直播、DRM 保护内容及部分特殊流暂不支持。退出应用后下载停止，重新打开后需手动继续。

实际速度取决于来源服务、账号权限与网络状况。播放地址过期时，继续或重试下载会重新解析；来源不再可用时可能仍会失败。

## 平台与接口兼容

以下对应当前已发布的 macOS 1.2.0 和 iOS / iPadOS 1.2.0 build 28：

| 能力 | Mac | iPhone / iPad |
| --- | --- | --- |
| 系统播放器 / VLC | 支持 | 支持 |
| mpv 与 VideoToolbox 硬解 | 支持 | 不提供 mpv |
| CMS JSON/XML | 支持 | 支持 |
| CatVod `.js` / `.js.md5` | 内置引擎 | build 28 内置引擎，可独立使用 |
| 网盘凭据设置入口 | 支持 | build 28 尚未提供 |
| Android Java/DEX JAR | 需要兼容的外部运行环境 | 需要兼容的外部运行环境 |

Mac 上需要登录的网盘资源，可在“设置 → 网盘设置”中配置凭据。Cookie、Token 等属于账号凭据，请勿粘贴到公开 Issue 或截图中。

## 常见问题

### 为什么首页、年份或类型选项不完整？

这些信息取决于来源实际提供的分类、筛选条件和影片元数据。尝试切换来源；来源停止服务或返回空数据时，应用无法补出完整片库。

### 为什么可以看到影片，但播放失败？

能读取详情不代表播放地址仍有效。可尝试其他线路；部分网盘资源需要账号，部分来源依赖网页嗅探、额外解析器或不受支持的规则。反馈时请提供界面错误提示及复现步骤。

### 手机端还需要电脑运行 Gateway 吗？

移动端 build 28 已内置 CatVod 引擎，`.js` / `.js.md5` 接口不需要电脑或外部 Gateway。更早的移动端构建和 Android Java/DEX JAR 不适用此说明。

### 去哪里反馈问题？

到 [Issues](https://github.com/shareu007/tvbox-Swift-macOS/issues) 说明系统与设备、应用版本、操作步骤、预期结果和实际结果。提交日志或截图前，移除账号凭据、私人接口和本机个人路径。
