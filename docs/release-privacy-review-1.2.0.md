## Standards

发现 2 项行为问题，均已修复：

1. HLS 任务在最后一段越过 100 GiB 后失败，重试可能复用全部已下载片段并跳过总量检查。现于复用前和写入完成清单前校验总量；稀疏文件回归覆盖超限后重试，不分配等量磁盘空间。
2. 空字符串或空白 `type_name` 阻断 `vod_class` / `vod_tag` 回退，导致类型筛选遗漏。现将空白字段视为缺失，保留非空主字段优先级。

未发现额外的构建输出、签名材料、配置跟踪或实质性代码规范阻断项。主题场景测试的专用模块缓存改为真实路径，避免 worktree 符号链接造成重复模块导入。

## Spec

发现 3 项确认的问题，均已修复：

1. 海报请求的来源自定义凭据头或带签名的 Referer，可能随跨域重定向继续转发。现跨域创建无继承头的新请求，拒绝 HTTPS 降级和目标 URL 的内嵌账号密码，并逐跳判断来源；同源认证继续保留。该项为可触发的隐私风险，审计没有实际用户凭据泄露的运行证据。
2. 分类请求失败或首页加载取消时，并发预取列表可能继续运行。现提前安装清理逻辑，并向正在等待的预取任务传递取消。
3. 夸克播放缓存仅查询根目录第一页，缓存目录位于后续页面时可能重复创建目录。现分页定位目录；达到有界搜索上限时明确失败，不创建重复目录，不删除或覆盖用户文件。

另外补强共享媒体抽检：取得最多 8 KiB 样本后取消该次传输，继续复用共享会话，避免不支持 Range 的服务持续发送完整媒体。回归测试验证取消与后续会话复用。

“其他推荐”最多抽取 3 个未覆盖分类，是既有有界请求测试明确约束的性能限制，保留行为并修正误导性注释；完整分类仍可通过分类导航访问。此项不作为缺陷或发布阻断。

两个审查代理复核修复后均未发现剩余的明确安全或功能阻断项；这不代替下述动态验证。

## 隐私核对

- 扫描待发布提交可达的完整源码历史；疑似凭据 URL 均为保留示例域名的合成测试输入。未发现真实密钥、个人签名标识、本机绝对主目录或私人接口配置。
- 新提交作者和提交者沿用上次公开版本的身份或 GitHub noreply 身份；不新增私人邮件地址。
- Release 强制使用空接口预设；打包剥离本机调试映射并重新签名，随后检查整个应用及扩展属性中的本机路径、凭据模式、运行数据库、诊断日志、签名文件和外部符号链接。
- 发布源码只同步当前分支的已审查历史到既有个人 fork 的上游分支，不推送本地其他实验分支。
