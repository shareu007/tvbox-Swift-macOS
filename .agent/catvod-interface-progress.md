# CatVod 接口适配进度

日期：2026-10-14。基线：GitHub main / 5cce765（1.1.0）。

## 目标

在远端稳定版上适配用户指定的 CatVod 校验入口，包括目录、首页、海报、分类、搜索、详情和播放。保留远端播放器结构，不恢复此前撤回的 1.2 界面改动。

## 已实现

- 有效 MD5 清单对应的脚本允许受约束的公开 CDN 跳转；清单和未校验 JS 保留准确 URL 白名单。逐跳阻断私网、附带凭据的目标与 HTTPS 降级，跨域不传入口认证信息，下载大小、次数和摘要校验继续生效。
- 中文 provider 路径支持 Unicode 字母和数字，并严格拒绝换行、路径穿越及编码后的额外路径段。
- 第三方子进程仅收到站点标识、路由和初始化参数，不收到入口 URL、应用 Cookie 或网盘凭据。
- 识别本地 imageProxy 包装，提取真实海报地址与必要请求头。沿用已有请求重定向与大小限制。
- 豆瓣推荐目录点击后在已有导航栈搜索同名影片；搜索排除通知/推荐目录，并为普通影视保留名额。
- CatVod 夸克剧集由受信任父进程解析，使用 TVBox 已保存 Cookie；区分缺失和失效登录，原画受限时复用同一已保存文件获取转码地址并提示画质变化。
- 播放缓存按账号和资源隔离，同一文件并发请求串行复用，不删除用户添加的文件。扫码登录等待有效的登录 Cookie。

## 验证

- 入口实际下载：6,479,654 字节，MD5 验证通过，现代生命周期补丁匹配成功。
- 受限子进程实际取得 96 个站点。
- 脱敏入口/路由回归最初 18 项有 10 项失败；补齐后通过。增加准确白名单目标也不得 HTTPS 降级的红绿回归。
- 夸克完整 Gateway 请求回归先复现旧版空地址/错误认证行为，再验证新路径；包括并发复用、缓存冲突、原画限制、失效账号和凭据域隔离，全部用合成数据。
- Gateway 全组 88 项通过，macOS 相关 96 项通过、0 失败；macOS Release 构建成功。原播放器文件未修改，相关 16 项回归通过。
