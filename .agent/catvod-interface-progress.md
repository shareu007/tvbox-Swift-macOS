# CatVod 接口适配进度

日期：2026-10-14。基线：GitHub main / 5cce765（1.1.0）。

## 目标

在远端稳定版上适配用户指定的 CatVod 校验入口，包括目录、首页、海报、分类、搜索、详情和播放。保留远端播放器结构，不恢复此前撤回的 1.2 界面改动。

## 已实现

- 有效 MD5 清单对应的脚本允许受约束的公开 CDN 跳转；清单和未校验 JS 保留准确 URL 白名单。逐跳阻断私网、附带凭据的目标与 HTTPS 降级，跨域不传入口认证信息，下载大小、次数和摘要校验继续生效。
- 中文 provider 路径支持 Unicode 字母和数字，并严格拒绝换行、路径穿越及编码后的额外路径段。
- 第三方子进程仅收到站点标识、路由和初始化参数，不收到入口 URL、应用 Cookie 或网盘凭据。
- 识别本地 imageProxy 包装，提取真实海报地址与必要请求头。沿用已有请求重定向与大小限制。
- 豆瓣推荐目录点击后在已有导航栈搜索同名影片；搜索排除通知/推荐目录，并为普通影视保留名额。
- CatVod 夸克剧集由受信任父进程解析，使用 TVBox 已保存 Cookie；区分缺失和失效登录，原画受限时复用同一已保存文件获取转码地址并提示画质变化。
- 播放缓存按账号和资源隔离，同一文件并发请求串行复用，不删除用户添加的文件。扫码登录等待有效的登录 Cookie。

## 验证

- 入口实际下载：6,479,654 字节，MD5 验证通过，现代生命周期补丁匹配成功。
- 受限子进程实际取得 96 个站点。
- 脱敏入口/路由回归最初 18 项有 10 项失败；补齐后通过。增加准确白名单目标也不得 HTTPS 降级的红绿回归。
- 夸克完整 Gateway 请求回归先复现旧版空地址/错误认证行为，再验证新路径；包括并发复用、缓存冲突、原画限制、失效账号和凭据域隔离，全部用合成数据。
- Gateway 全组 88 项通过，macOS 相关 96 项通过、0 失败；macOS Release 构建成功。原播放器文件未修改，相关 16 项回归通过。
- 实际抽样：推荐目录、中文课程源和三个普通影视源能读取首页/分类；三个影视源对公开片名的搜索、详情和直接播放地址解析通过。一个分享目录的首页返回来源错误，尚不视作可用；目录可加载不表示 96 个站点全部可播放。
- 媒体探测携带来源认证头被自动审批拒绝，未绕过。改用无 Cookie/Authorization/Referer 的公开地址检查，带认证信息或查询参数的地址跳过。真实网盘账号播放仍需用户实测。
- 安装包实际内置 Node 22 的 88 项 Gateway 回归通过；真实目录及六个抽样来源的结果与开发运行时一致。
- 无认证公开媒体检查：一个普通影视来源收到 HTTP 206 媒体数据；另外两个返回带查询参数的地址，按检查边界跳过。未声称所有影片、字幕或完整画面已经验证。
- 源码与安装包隐私检查、严格签名验证通过。1.1.0（构建 22）已替换本机安装包，二进制与审计产物一致，原远端构建 13 保留为临时 .bundle 备份。
- 实际界面工具仍返回 cgWindowNotFound，当前系统检查未返回可判断的锁屏标志，因此不能确定最后一次窗口访问失败的原因。确认只有一个正式安装版进程运行；未把窗口控制错误当作崩溃或界面验收通过。已请求解锁以继续实际界面测试。

真实入口、认证信息、远程脚本和业务响应只用于私有临时目录，不放入仓库或测试样本。发布前执行源码和安装包隐私检查。本轮不推送 GitHub、不上传 DMG。

## 2026-10-15：资源抽检与速度

- 普通 CatVod 的播放 ID 不再直接跳过检测；先执行只读 Spider 解析，再验证首个媒体样本。网盘只读边界由父进程统一拦截，不触发账号转存。
- 合并相同在途请求并短期缓存成功目录响应，立即显示已加载剧集，为每个资源添加 12 秒总预算；保留取消、备用线路和过期状态语义。
- 三组红绿回归复现并修复上述问题。133 项相关 macOS 回归、系统 Node 和内置 Node 各 99 项 Gateway 回归通过。
- 三个真实普通影视来源的搜索、详情与播放地址解析通过；重复详情从首次约 0.7–0.9 秒缩短到不足 1 毫秒。一个无认证公开地址通过媒体样本抽检；不把返回地址本身当作媒体可用证据。
- 本轮构建号 23。测试和打包产物放入临时 `.noindex` 目录，避免重新出现多个 Spotlight 应用副本。此前旧安装包与回滚副本已按用户要求清理。
- 源码与最终安装包隐私审计、严格签名检查通过。构建 23 已替换本机安装版，完整文件内容与审计产物一致，旧构建 22 及本轮测试应用副本均已删除；Spotlight 只保留正式安装版。
- 界面工具返回 native pipe startup failed，无法完成实际鼠标交互验收；未把后台功能测试当作真实界面验证。私有实测脚本与响应摘要已移除。
