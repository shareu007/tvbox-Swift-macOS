# 离线缓存下载

## 总目标

从影片详情选择线路和剧集，持久化下载到此设备，在断网或接口不可用时从下载管理播放本地文件。开发默认只构建和验证，明确收到本次安装要求后才更新本机安装版。

## 实现进度

- [x] 独立下载任务模型、私有目录和持久化队列；重启后恢复为暂停状态。
- [x] HTTP 媒体流式写盘，使用 Range / If-Range 安全续传，服务器不支持时从头下载。
- [x] 普通点播 HLS 主清单选择、有限分片并发、AES-128 密钥和初始化片段本地化。
- [x] 详情选集下载、下载管理、暂停、继续、重试、删除及离线播放入口。
- [x] 直链和普通 HLS 构建及焦点测试；合成 MP4 本地时长和内嵌字幕验证。
- [x] 实测发现系统播放器不能直接播放本地 M3U8，增加本地 HLS 引擎选择；mpv 真实离线硬解验证。
- [x] 真实 AES-128 用例发现 FFmpeg 限制本地密钥扩展名，改用生成的 `.key.ts` 名称，保持协议限制。
- [x] 28 项离线下载测试、39 项相关回归通过；源码隐私审计通过，完成独立本地提交。

## 边界

- 复用当前来源的播放解析和网盘登录状态；接口返回的实际媒体须可通过 HTTP 读取。
- 同时下载最多 2 个任务，每个 HLS 最多 4 个片段。直播、DRM、独立音视频轨和字节范围 HLS 暂不支持，明确显示原因。
- 直链续传依赖服务器范围请求和资源验证标识；HLS 只复用完全相同清单的完整片段。签名链接变化时重新下载，避免混合内容。
- 已完成文件位于 Application Support/TVBox/OfflineDownloads，排除系统备份；索引不保存解析后的签名地址及 Cookie/Authorization 请求头。源剧集 ID 属于私有记录，文件权限 0600，目录权限 0700。
- 退出应用不继续后台下载；重新打开后由用户选择继续。
- iOS 运行验证被本机缺少 iOS 26.5 平台阻断；未安装开发平台或应用。详细使用、支持边界和验证记录见 `docs/offline-downloads.md`。
